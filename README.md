# ClaimSnap Frontend - User & Admin Portal

This repository contains the React frontend for **ClaimSnap**, built with Vite and Tailwind CSS.

## Core Features
* **Claim Submission Flow**: A sleek, multi-step interface for users to submit policy details and capture video/images.
* **Real-time Status UI**: Displays the system's decision and the AI's exact confidence score.
* **Adjuster Portal**: A secure dashboard for adjusters to review flagged claims and execute human-in-the-loop overrides.
* **Custom Toast Notifications**: Premium UI feedback banners replacing native browser alerts.

## Tech Stack
* React (Vite)
* Tailwind CSS
* Lucide Icons
* React Router
